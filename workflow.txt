### 🔄 End-to-End Operational Workflow

The application runs on a continuous loop from data processing to user interaction:

#### 1. The Offline Machine Learning Pipeline (`train.py`)
* **Ingestion & Prep**: `preprocessing.py` reads `Thales_Group_Manufacturing.csv`, cleans column spacing, encodes target metrics (`Efficiency_Status`), and splits data.
* **Feature Engineering**: `feature_engineering.py` creates mathematical models matching realistic equipment fatigue.
* **Model Training**: `model_training.py` trains three candidate classifiers (Random Forest, XGBoost, Logistic Regression) to predict machine efficiency levels.
* **Serialization**: The best performing models, standard scaler, and feature encoders are serialized (`.pkl`) and saved to the `models/` directory for use by the backend API.

#### 2. The Real-time Backend Engine (`api.py`)
* **Startup**: FastAPI starts, loads the massive `Thales_Group_Manufacturing.csv` dataset, and loads all `.pkl` models into memory.
* **Data Processing**: Computes live rolling metrics from the latest timestamps in the CSV (calculating OEE, composite AI Health scores, and tracking threshold violations).
* **Endpoints**: Exposes REST interfaces supporting:
  * Telemetry states for individual machines (`/api/machines/{id}`).
  * Predictions using whichever model is set as active (`/predict`, `/predict_batch`).
  * Safety thresholds configured dynamically (`/api/settings`).
  * Copilot capabilities (`/api/copilot`).

#### 3. The Interactive AI Copilot (`local_csv_ai.py`)
* When a user queries the Copilot chatbot in the interface, the request is directed to the `/api/copilot` endpoint.
* `LocalCSVAI` interprets the query (using regular expressions and pattern matching):
  * **Analytical Intents** (e.g. *"Compare Machine 2 and 4"*, *"Show Machine 12"*): The parser instantly queries pandas internally, processes correlations, flags outliers, compiles a detailed Markdown table, and structures a visual Recharts dataset.
  * **Free-form NLP Queries**: If a local **Ollama** model (like `llama3`) is running on port `11434`, it acts as a fallback, utilizing a prompt enriched with factory statistics to respond intelligently.

#### 4. The Frontend Presentation Layer (React + Vite)
* The Vite dev server delivers a sleek web panel that fetches data continuously from the backend server.
* Key UI functions include:
  * **State Management**: Displays critical machines first using high-impact warnings (Critical 🔴, Warning 🟡, Healthy 🟢).
  * **Dynamic Customization**: Allows managers to modify active models (e.g. switch from XGBoost to Random Forest) and adjust safety boundaries (e.g. warning on temperature when exceeding `78°C`).
  * **Data Representation**: Uses high-performance components (like Recharts) to render power distribution, performance targets, and OEE percentages in a unified interface.
